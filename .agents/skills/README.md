# Project skills

This directory includes the installed snapshot of 21 skills from
[samber/cc-skills](https://github.com/samber/cc-skills), with their references,
assets and evaluations. Each `SKILL.md` carries its own version and metadata.
The skill instructions and original license are preserved. Two reference files
use equivalent Markdown hard line breaks instead of trailing spaces to satisfy
the repository whitespace check.

For MikroDash work, read [CLAUDE.md](../../CLAUDE.md),
[CONTRIBUTING.md](../../CONTRIBUTING.md) and [AGENTS.md](../../AGENTS.md) before
applying a skill. Repository instructions and authorization rules take
precedence. Open the selected skill's `SKILL.md` and load its supporting files
when needed.

These are development tools, excluded from the Docker build context. They are
not runtime dependencies of MikroDash.
